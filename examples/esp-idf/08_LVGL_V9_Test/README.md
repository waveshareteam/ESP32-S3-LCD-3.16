# 08_LVGL_V9_Test

[English](README.md) | [简体中文](README_ZH.md)

## What It Does

Runs the LVGL 9 music interface on the RGB LCD.

## Hardware Required

ESP32-S3-LCD-3.16 development board and a USB data cable.

## How to Run

Open an ESP-IDF terminal in this directory and run with an ESP-IDF version listed in the repository README:

```bash
idf.py set-target esp32s3 build flash monitor
```

## Expected Result

The LCD displays the LVGL music demonstration.

## Troubleshooting

This is a graphical music-player demonstration without audio output.
